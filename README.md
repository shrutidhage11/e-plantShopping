# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux based online plant shopping application.

## Features

- Landing page with Paradise Nursery branding
- About Us page
- Plant listing with three categories
- Six unique plants per category
- Plant thumbnails, names and prices
- Add to Cart functionality
- Disabled Add to Cart button after a product is added
- Dynamic cart item count
- Shopping cart with quantity controls
- Remove items from cart
- Dynamic item totals and cart total
- Checkout message
- Continue Shopping navigation

## Technologies Used

- React
- Redux Toolkit
- React Router
- JavaScript
- CSS
- Vite

## Run Locally

```bash
npm install
npm run dev
```
