# Paradise Nursery Shopping Application

A responsive React shopping cart application for an online plant shop. Browse houseplants by category, add items to the cart, change quantities, remove items, and view the subtotal.

## Features
- Landing page with Paradise Nursery branding and Get Started button
- About Us page
- Three plant categories with six plants each
- Add-to-cart controls and dynamic cart item count
- Cart quantity increment/decrement and delete controls
- Dynamic item totals and cart subtotal
- Checkout message and continue-shopping navigation

## Technologies
React, Vite, Redux Toolkit, React Redux, CSS

## Run locally
1. Install Node.js (18+ recommended).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.
